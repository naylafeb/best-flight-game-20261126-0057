Meridian Run is a 3D flight game: fly a jet through ten glowing rings over a procedural valley — coastline, river, mountains and a town — then land back on the runway. Keyboard and mouse controls, no network, runs from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
